# shiny-mobile-test

Flutter Android APK build test project.

## Build

This public test repository builds a debug APK with GitHub Actions.

1. Open the repository on GitHub.
2. Go to Actions.
3. Run `Build Android APK`, or push to `main`.
4. Download the uploaded APK artifact.

Current test APK name:

`Shiny_Mobile_Test_v0.1.2-test.apk`

Do not commit passwords, API keys, `.jks`, `.keystore`, or `key.properties` files.
